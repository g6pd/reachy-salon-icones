# Icônes du salon Reachy

Deux images, rien d'autre : l'icône de l'application « Salon des personnages » (projet personnel Reachy Mini × Claude × Voxtral).

Elles sont ici, en public, parce que Chrome sur Android fait fabriquer le paquet d'une application web par un serveur de
Google, qui doit pouvoir télécharger l'icône lui-même. Le salon, lui, tourne sur un réseau privé à la maison.
